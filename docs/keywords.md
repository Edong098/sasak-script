# Kamus kata kunci

Kata kunci berikut ditetapkan oleh pemilik proyek dan tidak diubah otomatis.
Seluruh keyword pada tabel sudah diimplementasikan dan dicakup oleh pengujian lexer serta runtime.

| Konsep | Kata kunci |
| --- | --- |
| Variable declaration | `pengaq` |
| Print | `gitaq` |
| If | `lamun` |
| Else | `deq` |
| Function | `gaweq` |
| Return | `sempuleq` |
| While | `semasih` |
| Break | `mengenteng` |
| True | `tetu` |
| False | `salaq` |
| Null | `deq_araq` |
| And | `dan` |
| Or | `atau` |
| Not | `bukan` |
| Class | `bale` |
| Constructor | `sandiang` |
| This | `niki` |
| New | `jariang` |
| Extends | `tunang` |
| Super | `lokaq` |
| Static | `melengo` |
| Import | `temang` |
| Export | `sugulang` |
| Try | `cobaq` |
| Catch | `bauang` |
| Throw | `pelewas` |
| Async | `liwatin` |
| Await | `anti` |

Padanan `for` dan `continue` belum ditentukan dan memerlukan persetujuan pemilik proyek.
