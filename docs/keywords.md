# Kamus kata kunci

Kata kunci berikut ditetapkan oleh pemilik proyek dan tidak diubah otomatis.
Seluruh keyword pada tabel sudah diimplementasikan dan diuji.

| Konsep | Kata kunci |
| --- | --- |
| Variable declaration | `pengaq` |
| Print | `gitaq` |
| If | `lamun` |
| Else | `deq` |
| Function | `gaweq` |
| Return | `sempuleq` |
| While | `semasih` |
| Break | `mengenteng` |
| For | `untuk` |
| Continue | `lanjutkan` |
| True | `tetu` |
| False | `salaq` |
| Null | `deq_araq` |
| And | `dan` |
| Or | `atau` |
| Not | `bukan` |
| Class | `bale` |
| Constructor | `sandiang` |
| This | `niki` |
| New | `jariang` |
| Extends | `tunang` |
| Super | `lokaq` |
| Static | `melengo` |
| Import | `temang` |
| Export | `sugulang` |
| Try | `cobaq` |
| Catch | `bauang` |
| Throw | `pelewas` |
| Async | `liwatin` |
| Await | `anti` |

`untuk` adalah padanan resmi `for`; `lanjutkan` adalah padanan resmi `continue`.
Sintaks: `untuk (pengaq i = 0; i < 5; i = i + 1):`.
`lanjutkan` akan melewati sisa iterasi saat ini dan melanjutkan iterasi berikutnya;
berbeda dengan `mengenteng` yang keluar dari loop.
